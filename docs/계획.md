# 작업 계획과 진행

1. ROM 구조 분석: LZ11 로케일·글꼴·셀·타일맵 형식, ARM9 글리프 조회·내장 글꼴·무결성 검사 범위 확인.
2. 용어집 작성 후 54개 로케일 직접 번역(외부 기계 번역 미사용), 표기 통일 검사.
3. 글꼴: 원본 색인 스타일 분석 → 갈무리·나눔스퀘어 네오·서울한강체로 한글 범위 추가.
4. 그림 글자 전수 검사(배경 359장·셀 8,693장 렌더링 후 분류)와 교체.
5. 헤드리스 에뮬레이터 검증, 실행 훅으로 화면별 글꼴·문자열·힙 여유 측정 후 글꼴별 음절 집합 조정.
6. xdelta `-0 -S none` 생성과 왕복 복원 검증.
