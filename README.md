# 마이트 앤 매직: 클래시 오브 히어로즈 NDS 한글패치 1.0.0

북미판 『Might & Magic: Clash of Heroes』(Ubisoft / Capybara Games, 2009)의 한국어 패치입니다. 대사·내레이션·메뉴·설명과 그림 글자를 외부 기계 번역 없이 직접 번역했습니다.

## 파일과 적용
릴리즈의 `Clash_of_Heroes_KR.xdelta`를 원본 ROM에 적용합니다. 원본은 북미판 CHNE(En/Fr/Es)이며 SHA-256은 다음과 같습니다.

`c2f47af33d2102985adb0925c4740e55080a8202389cfa8e3f67a53231a49011`

```powershell
.\xdelta.exe -d -s "Might & Magic - Clash of Heroes (USA) (En,Fr,Es).nds" Clash_of_Heroes_KR.xdelta "클래시오브히어로즈_한국어.nds"
```

결과 ROM SHA-256: `05547a842123cbb7c06a21c665b6480722f10b82221e68a61b1e2534979b0bfb`. 패치는 `-0 -S none`으로 생성했고 복원 결과의 해시 일치를 확인했습니다. ROM은 배포하지 않습니다.

게임 첫 화면의 언어 선택에서 태극기가 있는 **한국어**(원래 English 자리)를 고르면 됩니다. 프랑스어·스페인어는 원본 그대로입니다.

## 번역 범위
- 영어 로케일 54개 파일의 문자열 2,992슬롯(고유 문장 2,757개) 전부 번역(미번역 0). 5개 진영 캠페인 대사·내레이션, 튜토리얼, 퀘스트, 유닛·능력·아티팩트·주문 이름과 설명, 메뉴·시스템 문구, 제작진 직함.
- ARM9 고정 문구: 타이틀 안내(내장 기본 글꼴 대신 파일 글꼴을 쓰도록 이름 비교 문자열만 변경), 로딩·전원 끄기·무선 통신 오류 문구.
- 그림 글자: 전투 배너(아군 턴·적 턴·승리·패배·영웅 주문), 레벨 업 연출 9프레임, 턴 표시 11종, 장착 표시 2종, 여관 간판, 네크로폴리스·인페르노 지역 표지판 8종, 인트로 세계지도 지명 8개, 부팅 저작권 고지.
- 언어 선택·메인 메뉴의 미국 국기 → 태극기.

## 폰트
- 공식 [갈무리 v2.40.4](https://github.com/quiple/galmuri/releases/tag/v2.40.4): 대사·메뉴 등 작은 글꼴(갈무리 7·9·11), 그림 글자(갈무리 7·9·11 Bold·14).
- 큰 제목·버튼 글꼴: 나눔스퀘어 네오(cBd·dEb), 장 제목 세리프 글꼴: 서울한강체 EB.
- 원본 글꼴의 행별 그라데이션·외곽선 색인을 분석해 한글을 같은 스타일로 칠했습니다. 한글은 U+0100부터 상위바이트별 범위로 추가했습니다(게임의 범위 조회 구조 사용, 코드 수정 없음).

## 구조 메모
- `res/locales/*.en`: LZ11, u32 풀 길이·u32 개수·u16 오프셋·UTF-16 풀.
- `res/art/*.font`: u16 줄높이·u16 공백폭·s16 자간·u16 범위 수, 범위마다(상위바이트·개수·8바이트 글리프), u32 크기, 8bpp 픽셀(공용 0.pal 색인). 조회는 `하위바이트 <= 개수`로 검사하므로 쓰는 범위는 끝까지 빈 칸으로 채웁니다.
- `res/art/*.cel`: 프레임·파츠 뒤 8bpp 비트맵 묶음(8×8 타일 순서). `.set`/`.map`은 8bpp 타일셋·타일맵.
- ARM9의 내장 0.font 사본·코드 영역은 무결성 검사 대상이라 바꾸지 않습니다.
- **메모리**: 화면마다 글꼴 여러 개가 동시에 상주해 힙 여유가 적습니다. 글꼴마다 실제로 그리는 문자열의 음절만 넣었습니다(실행 훅으로 화면별 사용 글꼴 확인).

## 검증과 한계
- 창 없는 DeSmuME 코어를 내부 입력 API로 조작해 콜드 부팅·저작권 화면·언어 선택·타이틀·메인 메뉴, 캠페인 인트로 내레이션, 프롤로그 대사·자유 이동·NPC 대화, 유닛 획득 팝업, 튜토리얼 전투, 빠른 전투 준비·전투 시작을 확인했습니다.
- 프롤로그 사냥꾼 유닛 획득 장면의 힙 최저 여유 28KB(원본 202KB). 이후 장의 무거운 장면은 미검증입니다.
- **남은 영문**: 체험판 다운로드 플레이 종료 화면 1장(실제 팔레트를 얻을 수 없음), LV·HP·MP·XP·VS 약어, 버튼 문자, 로고와 Licensed by Nintendo 표기.
- 전체 플레이·실기 검증은 하지 않았습니다.

## 재현
Python 3.13과 `requirements.txt`. 원본 ROM과 `NanumSquareNeo-*.ttf`·`SeoulHangangEB.ttf`를 저장소 상위 폴더에, 갈무리 BDF(`Galmuri7/9/11/11-Bold/14.bdf`)를 `work/fonts/galmuri/`에 둡니다.

```powershell
python -X utf8 tools/extract_src.py   # 원본 ROM에서 원문 목록 생성(저장소 미포함)
python -X utf8 tools/build.py         # 한국어 ROM 빌드
```

번역 원고는 `translation/ko/*.json`, 용어집은 `translation/glossary.md`입니다. 인트로 세계지도·저작권 고지 패치는 원작 화면에서 복원한 팔레트(`translation/gfx/pal_map*.json`, 저장소 미포함)가 있어야 적용되며, 없으면 건너뜁니다.
